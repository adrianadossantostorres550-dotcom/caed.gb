# CAEd Math Lab 9

Plataforma de estudos de Matemática para a preparação do CAEd do 9º ano.

- Modo Misto, Simulado (correção só no final), Revisão e Desempenho
- Meta diária (padrão: 100 questões) e nome do estudante
- O progresso fica salvo no navegador (localStorage), sem sincronização entre aparelhos

## Como usar

Abra `index.html` no navegador. Para publicar: GitHub + Vercel (ou GitHub Pages).

## Banco de questões

Atualmente com 20 questões conferidas, 2 por módulo. A ampliação é feita em lotes.
